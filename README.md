# mapa-da-ciencia

Observatório da literatura científica. O `mapa-da-ciencia` coleta milhares de artigos, começando pelo SciELO. Com modelos de linguagem rodando na sua própria máquina, ele faz três coisas:

- mapeia os tópicos do corpus e acompanha como mudam ao longo do tempo;
- classifica cada resumo segundo um codebook definido por você, com validação contra a sua codificação;
- mostra a geografia da produção por UF, país e instituição.

> **Status:** em desenvolvimento (marco M0, spikes técnicos). Ainda não há versão utilizável.

Este projeto é o sucessor do [SciELO-Summarizer](https://github.com/felipelmc/SciELO-Summarizer), criado no SICSS Brasil 2024.

É um projeto independente e **não oficial**: não tem vínculo com o SciELO, o OpenAlex ou o IBGE, cujos dados públicos ele usa.
